## Descripción
Plataforma web para la gestión de reservas, flota y devoluciones de una
empresa de alquiler de vehículos, con tres roles: Cliente, Empleado y
Administrador.

## Tecnologías
- Base de datos: PostgreSQL
- Backend: Express.js
- Frontend: Next.js

## Estructura del repositorio
- `/docs` — Informe, diagrama ER y documentación del proyecto
- `/database` — Scripts de base de datos
- `/backend` — API REST (Express.js)
- `/frontend` — Aplicación web (Next.js)
